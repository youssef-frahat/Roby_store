# Roby Store — Brand Identity & Design Tokens

## Brand Overview
- **Brand Name**: Roby Store
- **Tagline / Vertical**: Women's Fashion & Luxury Home Textiles (أزياء حريمي ومفروشات راقية)
- **Brand Essence**: Feminine elegance, modern chic, home comfort, and warmth.

---

## Color Palette (Warm Blush & Champagne)

| Token Name | Hex Code | Role & Usage |
| :--- | :--- | :--- |
| **`primary` (Dusty Rose)** | `#D4A5A5` | Main brand accent, active states, key highlights |
| **`primary-dark` (Muted Rose)** | `#B57E7E` | Hover states, borders, active toggles |
| **`secondary` (Warm Champagne)** | `#F7EDE2` | Soft background panels, card surfaces, badges |
| **`accent` (Champagne Gold)** | `#D4AF37` | Promotional badges, discount tags, rating stars |
| **`surface` (Linen White)** | `#FAF7F2` | Page background, clean aesthetic |
| **`text-primary` (Deep Charcoal)** | `#2B2D42` | Primary typography, headers, body text |
| **`text-secondary` (Muted Slate)** | `#6C757D` | Secondary labels, descriptions, metadata |
| **`success`** | `#2A9D8F` | In-stock tags, completed order checks |
| **`danger`** | `#E76F51` | Out-of-stock badges, form validation errors |

---

## Typography Guidelines
- **Headings / Brand Display**: Modern Serif (e.g., `Playfair Display`, `Cormorant Garamond`, or sleek `Cinzel`)
- **Body & Interface**: Clean Modern Sans-serif (e.g., `Inter`, `Plus Jakarta Sans`, or `Tajawal` for Arabic)
